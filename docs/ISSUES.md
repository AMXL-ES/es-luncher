## 仍存在（按优先级）
1. **没有安装包/便携包/自更新/签名**（M10）→ 不能对外称正式版
2. 微软登录 UI 已隐藏（缺 Azure client ID + 产品化）
3. NeoForge 未通、CurseForge 未接
4. Modrinth 安装/大文件下载**不可取消**；进度条是不确定态
5. 每次打开下载页都会读取 manifest（有缓存但仍是磁盘/网络动作）
6. 日志窗 1s 轮询，窗口最小化时仍在读
7. 图标磁盘缓存无限增长（`cache/icons`），需要清理入口/上限
8. 语言切换需重启（`{app:T}` 在加载时求值）
9. 模组更新只能查，不能一键更新（提示里已改为“后续版本”）
10. 账户头像依赖 crafatar 外网；离线 UUID 显示首字母
11. 数据根旧机器回退到 `D:\mc-data` 是过渡逻辑，未来版本应迁移/提示
12. 150% 缩放未测；完整焦点顺序/读屏审计仍是基础级
13. UI 测试只有 1 个（Headless 深交互少）
14. 无代码签名 → Windows SmartScreen 会提示

## 建议下一版本优先
1. M10：Inno Setup 安装包 + 便携 zip + 自更新签名
2. 微软登录恢复（Azure client ID）
3. Modrinth 下载取消 + 真实进度
4. 图标缓存清理入口、日志轮询暂停
